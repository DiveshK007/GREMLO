# Gremlo for VS Code and Cursor

The status bar shows your pet, its mood and the current run's tool count. Click it for a panel where the pet walks.
Ordinary approvals can be answered from the editor; anything that deletes, pushes or spends says to answer on the
Mac. Answering anywhere clears the others. The sponsored line never appears here.

Talks to the Gremlo Mac app over its local socket. If the app isn't running, the extension says so and does nothing.

    npm install && npm run compile
    npx vsce package          # VS Code Marketplace
    npx ovsx publish          # Open VSX (Cursor)
