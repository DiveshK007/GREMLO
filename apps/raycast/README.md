# Gremlo for Raycast

Pause Pets, Start Focus, Say Something, Pet Status, Answer Next Approval. Each command sends one request to the
running Mac app over its local socket (`~/Library/Application Support/Gremlo/gremlo.sock`), the same one the
`gremlo` CLI uses. Nothing can spend, pay, change the payout address or allow a risky command.

    npm install && npm run dev

Needs an `icon.png` (512x512) before `ray build`.
